# 设计技能核对与本项目用法

2026-11-08 阅读作者仓库与官方说明，已安装 frontend-design、Impeccable、web-design-guidelines，固定提交及安装位置见 `design/skills-lock.json`。

本轮以 Impeccable 的 Operate 方法主导：让工具围绕读日志、发指令和看曲线组织，检查真实渲染、状态、密度和可读性。用户明确选择的紫色品牌、液态玻璃、左侧导航与双栏结构高于技能的通用偏好。frontend-design 作为备用设计资料，不再同时施加两套方向规则。Vercel 用于可访问性和实现检查。

## Taste Skill

来源：https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md

阅读时名称 `design-taste-frontend`，正文版本 2.5.1。当前主规则针对公司官网和产品展示页，包含首屏、整屏章节、图片和展示动效。旧索引仍可能显示更早版本的描述，不能将索引当作当前内容。

对本项目的判断：参考其整齐边界、真实内容和看图修正的方法；不把官网首屏、整屏章节与展示动画搬入桌面工作台。没有安装或执行 Taste 的 hooks 与脚本。

## Designing with Impeccable

来源：https://impeccable.style/designing/

这是官方使用指南，不是另一套独立 skill。指南说明产品上下文、方向选择、实现、检查、细节与设计记录的配合，并提醒重叠的设计指令可能牵扯方向。

本项目按用户选择直接写应用，截图作为验收依据，不生成另一轮待选概念。Impeccable 的初次引擎下载失败后，已用官方发布文件和技能自带 SHA256 校验恢复 Windows 启动器；未启用 hooks 或 live 模式。
