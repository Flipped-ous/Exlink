# EXLINK PRO V4.8 对应的软件 UI 基准

> Lissio 的最新源码级借鉴依据、真实视觉参数及布局映射见 [lissio-source-adaptation.md](lissio-source-adaptation.md)。本硬件映射仍保留；视觉规格进一步按该组件体系统一。

## 当前依据与范围

用户提供的《EXLINK PRO V4.8｜项目整体方案、完整硬件设计与原理图交接书》共 456 行，已完整阅读。硬件及整体需求方案已定，原理图、电气验证与实物尚未完成。文件中的原理图教学、绘图顺序和新会话启动消息是交接内容，本次不执行；当前工作仍是电脑助手的 UI 布局设计。

本文件更新此前软件设计建议的定位：软件优先配合用户这一款 EXLINK PRO 多功能调试器，再扩展其他通用调试功能。不是多型号设备管理平台。硬件配置仍以用户原始 V4.8 主文档为准，本文件不修改硬件架构。

最新用户界面要求：不让用户搭建节点；波形嵌入串口等工具；采用流体云设计语言，并加入苹果 Liquid Glass 的材质思路；允许用户自定义功能模块和布局。流体云在此作为本产品视觉方向，不冒称已有统一行业标准。

最新修订：取消波形高度数值滑块；自定义统一收进左下角设置，调试页不常驻自定义按钮或布局编辑栏。整体按成熟的工程应用设计，压低渐变、卡片、大圆角和装饰性标题，强调紧凑工具栏、明确状态和稳定的数据排版。玻璃材质仅轻量用于导航与辅助控制层。

## 硬件功能到 UI 的映射

| 主导航 | V4.8 依据 | 电脑界面的职责 |
| --- | --- | --- |
| 串口调试 | CH549G 的 UART/USB 调试通路 | 收发、HEX、时间戳、筛选、快捷命令；可嵌入波形和目标板参数面板 |
| 逻辑分析 | RP2040 的 8 路输入、PIO/DMA 及 USB 通路 | CH0–CH7、采集设置、时序与协议解码；具体采样率、触发及电平以固件与测试为准 |
| 智能电源 | 可调输出及一颗 INA226 | 输出设定与开关、输出 V/I/P、低速趋势、输入条件及保护状态 |
| 辅助测量 | 独立 VΩ/COM、ESP32 ADC1 与蜂鸣器 | 正直流测压与断电蜂鸣通断，两模式共用表笔；与输出监测分开 |
| SWD / 调试 | CH549G、WCH-Link/SWD | 实际连接识别、维护及外部开发工具联动；不先承诺自研完整调试器或通用烧录能力 |
| 扩展工具 | 后续软件扩展 | TCP/UDP、外部目标板图像协议、数据回放等逐项实现；可固定常用入口 |

电源和辅助测量属于这款产品的核心，应在主导航可达。网络与图像是可扩展软件工具，不能据此假设新增摄像头或其他硬件。PWM、I²C 扫描、任意模拟示波器等没有在 V4.8 中明确的能力，不自动列为硬件已定功能。

## 布局

左侧：工具导航及一个轻量 EXLINK PRO 连接状态，不设置设备管理首页。

顶部：当前工具、连接与必要配置；串口端口与波特率属于串口，电源设定属于电源，避免所有工具都套 COM3 模板。

中央：当前工具的数据和操作。串口工作台内可组合日志、波形、参数、快捷指令。新连接默认日志；数值解析配置完成后使用波形联调。数据采集不由面板的显隐决定。

底部：串口发送、必要状态与文件记录入口。日志与波形可以同屏；目标板参数需要明确通信协议，不因 EXLINK 连接成功就假设可以修改目标 MCU 内任意变量。

右侧：当前工具属性或 AI 按需展开。自定义布局改由设置页统一管理。小窗口优先只展开一个辅助面板。AI 是后期跨工具的可选辅助入口，不挤占核心调试导航。

## 自定义的三个层次

1. 工具入口：用户固定或隐藏扩展工具、调整顺序；实际不可用的工具说明依赖，不能只靠 UI 打开功能。
2. 工具内部模块：日志、波形、目标板参数、快捷指令的显隐、顺序、上下或左右排列、大小。先提供专注收发、波形联调、参数联调三种预设，再允许调整。
3. 外观：深浅主题、强调色、密度、云雾强度、玻璃质感及减少动效。恢复默认必须易于找到；布局数据带版本，防止升级后失效。

设置中的工作区页负责模块显隐、顺序和排列；外观页负责主题与材质。取消波形高度数值配置，波形区域随可用空间适配；后续可研究分隔条直接调整区域比例。预设可按工具保存；连接及未提交参数草稿不能因布局变化丢失。

## Lissio 功能借鉴顺序

依据官方介绍 https://lissio.pengheng.top/zh ，优先借鉴：

1. 波形时基缩放、暂停显示、游标测量，以及通道共用或独立 Y 轴，整合到串口或电源趋势工具内部。
2. 协议解析预览，将接收样例映射为通道。用表单、预设和结果表完成，不要求搭节点。当前稿仅提供本地文本 CSV/名称数值样例预览，不代表已接入设备解析链。
3. 记录与离线回放、按时间区间导出数据，服务于复查问题和比较参数变化。
4. 数值显示、通道表、频谱等可选模块。FFT 用于适合采样的数据源，不把低速 INA226 曲线包装成高速示波器。
5. UART/I²C/SPI 解码进入逻辑分析页；选择日志或曲线区间后调用 AI 属于后续辅助能力。

Lissio 的 CAN、工业通信等不能直接视为本机硬件能力；如增加软件支持，应明确适配器和协议依赖。节点画布、复杂脚本控件编辑器及自由数据流编排不进入默认使用路径。

布局编辑不得隐藏设备输出的关键状态、故障提示和关闭输出入口。降低透明度或切换低功耗外观不改变设备行为。

## 视觉设计

流体云：柔和的冷白/石墨底色、低饱和蓝紫与青色环境光、较轻的分隔、大范围柔和明暗过渡。云雾置于界面外壳，数据区域不用动态背景。

液态玻璃：主要用于侧栏、浮动工具条、菜单和辅助设置面板，使用通透层次、边缘高光、适度背景模糊和轻阴影。波形、日志、读数使用稳定的实色面板，保证读数和曲线可辨识。

苹果官方依据：https://developer.apple.com/design/human-interface-guidelines/materials 。这是借鉴材质与层级思路。当前网页设计稿使用跨平台 CSS 近似，未实现或宣称苹果原生 Liquid Glass 的完整光学效果。

## V4.8 对界面的硬约束

- 输出 V/I/P 来自可调输出的一颗 INA226；表笔电压来自独立 ADC 前端，必须分别命名、分别呈现。
- 目标输出范围 3.3–20 V、表笔正直流 0–30 V 仍是设计目标。输出功率、测量精度等未验证，不在界面里写成已达额定能力。
- USB 电脑输入和独立 PD 供电是不同使用场景。可用输出能力应由已验证的设备能力与当前输入条件决定，不能固定显示全电压 3 A。
- 当前未确定电池到可调输出的高功率路径，不能设计成电池模式必然支持高功率输出。
- 测压与通断在同一表笔下切换，真实模式切换需设备确认，带电检查及硬件保护不能由界面代替。
- 不新增 ESP32 与 RP2040 SPI，因此不承诺无线传输原始逻辑数据或设备小屏离线实时逻辑波形。
- SWD/WCH-Link 的调试能力与 ESP32 控制服务分开；识别到设备不代表所有子系统都已连接可用。
- OTA 默认只针对 ESP32；RP2040 与 CH549 的维护按原 USB 方式处理。

## 电脑端和设备小屏

电脑端采用可调整的模块工作台，便于多区域联调。设备约 2.1 英寸级小屏采用单任务页：当前输出、测压/通断、基础状态及设置。两端共享图标、配色、术语和状态含义，但不复制同一套多栏布局。

小屏的云雾和玻璃可用预渲染或简单静态渐变表达；具体效果以 ESP32 实机内存、帧率和功耗为准，不要求嵌入式端运行复杂实时折射。桌宠另作为后期状态/待机体验，不覆盖关键测量和输出状态。

## 本次交互稿的真实范围

已表现核心工具切换、设置页中的串口模块显隐及排序、上下/左右排列、玻璃质感、深浅主题及恢复默认；调试页保留三种常用视图预设及本地模拟发送。设置页新增本地样例解析预览。波形及日志是标明的示例。左右排列在窄窗口自动变为上下布局，波形高度随可用空间适配。

交互稿没有连接硬件、测量、输出、采样、烧录或 AI 能力。电源/测量/逻辑页面用于检查功能分区与未连接状态，实际控制禁用。布局可通过会话宿主提供的状态接口恢复；未提供宿主保存能力时仅当前预览内有效，不冒称已经实现桌面应用持久化。

正式应用仍需实现工具入口自定义、拖动缩放、布局导入导出、按工具保存预设、能力发现与真实控制协议。
