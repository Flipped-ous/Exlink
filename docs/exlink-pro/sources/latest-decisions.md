## 2026-11-26｜ESP32 框架选型（用户确认）

- 正式选择 PlatformIO + Arduino-ESP32 + FreeRTOS + LVGL；使用 C/C++、分层组件化、HAL/Mock HAL，必要时使用兼容的 ESP-IDF 原生 API。
- 选择理由：参考方屏与 ExlinkPro 的已有驱动方案，降低迁移和首板验证成本，当前需求未证明必须迁移纯 ESP-IDF。此结论不是可靠性实测结果。
- 不默认迁移原生 ESP-IDF 或 Arduino-as-component。若发现不可解决的 SDK、OTA 或性能瓶颈，提供证据、替代方案与迁移代价后再请用户决策。
