## 0. 先读：功能状态的定义与完成标准

状态字段按以下定义使用，不能随意用“支持”代替已完成：

- **A｜第一版必须具备**：已经列入正式产品需求，必须在首板原理图/硬件/固件中规划并最终验收。尚未完成时依然是待办。
- **B｜原版能力必须保留实现条件**：原博主项目已有该功能或原版明确列出，本次改版不得无意删掉；先确认复用的引脚、接口、电平与固件，再决定是否能在首版固件完整交付。若资源冲突，必须在 PCB 定稿前给出解决办法，而不是静默删除。
- **C｜软件阶段实现**：当前硬件选型为其预留能力，但要由独立固件/App/上位机开发完成；不表示出厂自带。
- **V｜必须验证**：电气、封装、结构、固件兼容或性能尚无实测结果；不能写成已量产性能指标。
- **X｜明确不增加**：用户已经否决，原则上不重新加入。

**所有功能的真正“完成”**至少同时满足：

- [ ] 对应外部接口、GPIO、供电、电平、保护、连线与封装已核对。
- [ ] 对应固件代码或上位机工作流程可执行。
- [ ] 有可操作的 UI/串口/USB/API 输入输出路径。
- [ ] 通过对照测试（正常、边界、异常、断连/重启）并有记录。
- [ ] 在最终完整双板 BOM、机械装配和功耗预算中没有冲突。

## 1. 产品目标与第一版功能总览

### 1.1 产品定位

面向嵌入式学习、MCU 开发、电子制作、智能车竞赛、外出检修的便携式多功能电子调试器。以两块四层 PCB、触摸屏和 1S 锂电池作为一体化硬件平台；提供电脑辅助下载调试、无线控制、智能电源、基础电气排故和可视化交互。

**核心优先级**：专业调试功能完整 > 供电和测量安全 > 结构可制造与长期可靠 > 续航 > BOM 成本与料号数量 > 界面及可玩性。

## 2. 博主原有功能：必须逐项继承的详细任务

### 2.1 F01｜DAPLink / ARM SWD 下载、调试

**用户可见效果**：连接电脑与一块 STM32 等兼容 MCU；下载 HEX/BIN/ELF 对应固件；可连接目标、运行/暂停、设置断点、单步与读取调试信息。

**硬件清单**：
- [ ] CH549G 正确供电、时钟、上电/复位、去耦及 USB 数据链。
- [ ] SWDIO、SWCLK、GND、复位/目标参考（如实际原版需要）合理引出；针脚方向和丝印清楚。
- [ ] 调试接口与外部可调电源正极、通断测量表笔完全分离。
- [ ] 保留初次烧录 CH549G 的 ISP/USB 恢复方法、U44 启动控制及调试焊盘；验证 U44 TXD 拉地不会在错误时序下硬短路推挽输出。
- [ ] 明确原版的 DAPLink、WCH-Link 和“通用 CMSIS-DAP”是不同固件/工具概念；正式列出兼容组合。

**固件/软件清单**：
- [ ] 获得可依法使用、可重现烧录的 CH549 固件与版本号。
- [ ] 完成初次烧录说明、目标连接/断连流程和错误提示。
- [ ] 在至少一款具体 ARM MCU 上验证烧写、断点和单步；记录 IDE/驱动/固件版本。
- [ ] 如宣称 RISC-V，另选明确支持的目标 MCU 单独测试，不能泛称所有 RISC-V。

**验收**：有连接图、上位机识别截图、烧录记录、断点调试视频/日志；测试目标和固件版本可追溯。

### 2.2 F02｜WCH-Link 模式

- [ ] 核实作者提供的 CH549 固件究竟支持哪些 WCH ARM/RISC-V 目标及模式切换方式。
- [ ] 若模式切换依赖 U44/ISP 上电条件，画出安全进入模式的电路并保留维护说明。
- [ ] 检查 SWD/其他调试引脚的电平限制和目标供电关系。
- [ ] 使用 MounRiver Studio 或作者指定的工具验证至少一个目标芯片；保留失败情形说明。
- [ ] 不宣称对所有 STM32/WCH 芯片型号通用。

### 2.3 F03｜有线串口助手 / USB 虚拟串口

- [ ] 明确串口 TX、RX、GND 在外接接口上的实际针号，电脑发送方向不要接反。
- [ ] 配置适用逻辑电平、串联电阻或原输入保护；禁止把 12V 直接连接 UART。
- [ ] 验证 CH549 的 USB 串口枚举方式、所需驱动、允许波特率及电脑识别名称。
- [ ] 固件支持常用波特率、数据位、校验位、停止位、十六进制/文本发送（取决于接口实现）。
- [ ] 电脑端支持换行符处理、时间戳、日志保存、过滤与断线重连。
- [ ] 测试 MCU→PC、PC→MCU 和双向连续传输，避免掉字节及反复重启。

### 2.4 F04｜RP2040 八通道逻辑分析仪

- [ ] 保留 RP2040、晶振、外置 Flash、BOOTSEL、RUN、USB D+/D− 与必要供电。
- [ ] `CHAN0`～`CHAN7` 全部引出，通道顺序对应丝印及上位机。
- [ ] 逐一复核原有 R46～R53 及 D30/D31/D32/D35 输入保护，不额外加入用户否决的新八路缓冲器。
- [ ] 在说明书中限定已验证的输入电平；未验证前不宣称支持 5V/12V 输入。
- [ ] 核实 PIO/DMA 缓冲、采样率、触发方式和电脑分析软件；标称采样率以稳定实测为准。
- [ ] 测试 1、2、4、8 通道采样、不同采样时长、触发停止、USB 数据连续传输。
- [ ] 在原版不具备 ESP32↔RP2040 内部数据路径时，**不承诺本机屏幕脱离电脑显示八路实时波形**。

### 2.5 F05｜USB HUB 多设备模式

- [ ] USB-C 的 D+/D− 进入 CH334F 上游；原 PD Sink 的数据脚/BC1.2 引脚不可与 USB HUB 数据驱动冲突。
- [ ] CH334F 下游向 CH549G、RP2040、ESP32 的实际 USB 设备端正确连接。
- [ ] 核对 HUB 的 3.3V/5V 配置、VBUS 检测及掉电行为；取消独立 USB 5V 不等于取消 USB 所需 VBUS 感知。
- [ ] USB 差分线阻抗、回流、ESD、连接器极性、双板过孔和板间连接器逐项检查。
- [ ] 电脑同时看到多 USB 功能设备，并可分别打开调试工具，不发生资源互抢。
- [ ] 区分“普通电脑 5V USB 模式”和“独立 12V PD 供电模式”，不能默认一根线同时连电脑又取得独立充电器的大功率。

### 2.6 F06｜博主数控电源：完整功能继承与升级

- [ ] 保留“在屏幕中设置输出电压、控制供电开关”的原产品体验。
- [ ] 用 MP28167GQ-A-Z 实现 3.3～20V 目标范围，替代旧 BUCK+数字电位器拓扑。
- [ ] 增加可设置的输出限流、软启动及故障态；实际是否能恒流取决于芯片配置和实测。
- [ ] MP5016H 作为输出电子保险丝，不能使用与 20V 正常输出冲突的钳位配置。
- [ ] 上电、复位、OTA、死机、电量不足时，对外输出硬件默认关闭。
- [ ] 通过 INA226 显示真实电流、功率，软件计算累计能量；明确采样间隔。
- [ ] 输入功率与温升约束：12V/3A 适配器的总输入只有 36W，不能承诺外部 12V/3A 连续输出同时还供给系统或充电。
- [ ] 无合适 PD 输入时限制/禁止较高功率输出，**电池模式不承诺 20V 大功率供电**。

### 2.7 F08｜I²C 地址扫描

- [ ] 核对原版外接 I²C 接口的 SDA、SCL、GND 及可选 3.3V 参考针；决定保留或重新引出。
- [ ] 选择 ESP32 可用 I²C 控制器 GPIO，不占用 PSRAM/Flash/启动/屏幕关键脚。
- [ ] **外部 I²C 应与 MP28167/SGM41513/INA226 内部电源控制总线避免直接无保护共用**，防止接错线使调压/充电失控；可以使用另一组 GPIO/I²C 控制器或妥善隔离/总线分段。
- [ ] 上拉阻值与电源域、电平相容；不允许向目标板错误注入 5V。
- [ ] 固件支持 7 位地址遍历、超时处理、总线被拉低恢复、结果展示。
- [ ] 用至少 2 类已知地址器件和故障总线验收，不只是扫描屏幕显示“发现设备”。

### 2.8 F09｜PWM 信号发生器

- [ ] 指定可输出的 ESP32 GPIO 和实际外接插针，明确 3.3V CMOS 信号，不是大电流电源输出。
- [ ] 评估 GPIO 串联阻抗、外部短路、反向电压和负载能力。
- [ ] 固件可设置频率、占空比、使能、停止；限制合法范围、确保重启时默认不输出。
- [ ] 用示波器/逻辑分析仪确认频率与占空比，检查最大负载下波形。
- [ ] 若与频率计共用单针，硬件必须具备明确安全的输入/输出切换和默认高阻状态。

### 2.9 F10｜数字频率计

- [ ] 识别外部输入和对应 GPIO/PCNT/定时器，不能把电源输出口当频率输入。
- [ ] 确定输入可接受逻辑范围、阈值、去抖、ESD 和保护，不自动承诺 5V 容忍。
- [ ] 支持测量模式、门控时间、平均/超时处理、无信号提示。
- [ ] 用标准函数发生器逐档测试 10Hz、1kHz、10kHz、100kHz 等代表值；更高上限按实测标注。
- [ ] 与 PWM/逻辑分析等功能同时运行时验证 GPIO 复用冲突。

### 2.10 F11｜简易示波器（原版功能）

- [ ] 追踪博主原版模拟采样引脚、分压、保护、滤波网络和频率限制，先确认新主板是否保留这些网络。
- [ ] 明确模拟信号允许的**正负电压范围**、输入阻抗、直流偏置、带宽、采样率、波形精度。
- [ ] 不把新增 0～30V 直流电压表直接认定成简易示波器：高阻分压和 100nF 滤波可能使带宽不足。
- [ ] 固件实现可连续采样、时间轴、纵向量程/自动缩放、开始/停止、触发简化功能。
- [ ] 以 10Hz/100Hz/1kHz 等低速正弦/方波为初始验证对象；最终可测频率及失真由实测决定。
- [ ] 如果原模拟前端与新辅助测量前端无法同时保留，应在 PCB 定稿前明确是新增安全模拟输入通路还是复用接口并牺牲部分带宽；**禁止在不告知的情况下删掉原版示波器**。

### 2.11 F12｜原版电压表与本版新增 VΩ 测压的关系

- [ ] 保留“独立测外部电压”的实际体验，不要把 INA226 的可调输出监测冒充外部电压表。
- [ ] 原版可能有既有 ADC 电压测试输入，需先查网表；与新 `VΩ/COM` 测量硬件可合理合并，避免重复两套模拟输入。
- [ ] 新版目标 0～30V **正直流**，COM 与整机系统 GND 共地，输入保护/范围/误差须实测。
- [ ] 屏幕展示小数、单位、输入超范围提示和校准信息。
- [ ] 禁止用于市电、负压、交流电压或浮地两点差分测量；不宣传完整万用表功能。

### 2.12 F13｜无线串口

- [ ] 核对博主原版 BLE 无线串口由哪组 UART/GPIO 直接连接到目标板。
- [ ] ESP32 通过 BLE 或 Wi-Fi 将 UART 数据转发到手机或电脑，支持双向发送及断线重连。
- [ ] 若新设计仅保留 CH549 的 USB CDC UART，没有把目标 UART 接到 ESP32，则**不能只靠刷 ESP32 固件实现无线串口**；需在原理图阶段保留对应连接。
- [ ] 串口电平、GND、公用波特率、缓冲溢出和异常数据处理需验证。
- [ ] 手机端提供可选文本/HEX、发送、接收、日志保存、连接状态；验证连续数据不会严重丢包。

### 2.13 F14｜无线下载器

- [ ] 明确**第一版首要支持的目标 MCU 家族**，不要在未验证前宣称无线烧录任意芯片。
- [ ] 复核博主 ESP32 无线下载方案的实际目标串口/SWD、BOOT/RESET/NRST 控制线路及连接器。
- [ ] ESP32 与 CH549G 之间原本没有专用的内部下载控制链路时，不得推断 Wi-Fi 自动转发 DAP 调试数据。
- [ ] 固件实现身份认证、目标选择、固件格式校验、烧录过程与失败恢复，涉及擦写前要二次确认目标。
- [ ] 电脑端/手机端提供上传固件和进度信息；对选定目标芯片实测整包烧录成功、断线恢复和坏包拒绝。
- [ ] 若无线下载器需要与“不要新增 ESP32↔RP2040 SPI”或外壳连接资源冲突，可改用其他**已有可用**的 ESP32↔目标连接；不能暗自新增被否决的跨主控 SPI。

## 3. 我们新增和升级的功能：必须实现的详细任务

### 3.1 F15｜USB-C PD 输入管理

- [ ] USB-C 插座 CC1、CC2、VBUS、GND、数据线及 ESD 正确布局。

- [ ] 采用 TPS63020 从 SYS 直接提供系统 3.3V，不重新生成独立固定 5V 电源。

- [ ] 长按开关机要实现可靠的系统启动、低功耗、关断/唤醒，不以 RESET 冒充电源开关。
- [ ] 低电量关断/充电温度异常、插拔电源、USB 断连时避免输出失控和异常重启。

### 3.3 F06/F07｜可调电源、保护和测量

- [ ] MP28167-A 反馈网络、I²C 寄存器配置、EN 启动时序、输入/输出电容、电感按具体后缀手册计算。

- [ ] 外部输出上电默认断开；配置并读回目标值、等待稳定、检查异常后再闭合输出路径。
- [ ] 外部反向电流阻断以官方推荐连接/器件额定为准。

- [ ] 提供 3.3/5/9/12V 等预设，限制电流，展示 V/I/P、记录工作时间与积分能量。
- [ ] 额定输出能力不能简单宣称“20V×3A”；在额定 PD 适配器、负载和封壳情况下逐档测试。

### 3.4 F18｜独立直流电压表 VΩ/COM

- [ ] 独立于电源输出 `VOUT/GND`，不能让两对端子物理或丝印混淆。
- [ ] 目标测量范围为 `0～30V 正直流`、系统共地、非隔离；不宣传专业 DMM 精度。
- [ ] 优先使用 ESP32 空闲 ADC1；高压分压候选为 1MΩ+1MΩ 与 100kΩ 等，最终按已有完整料号复核。
- [ ] 判断是否保留 0～6V 低压量程；如采用双量程，低压分路在 30V 误接时必须在任一 MUX/ADC 输入之前限幅保护。

- [ ] 软件提供量程切换、滤波、零点/多点标定、超量程提示。
- [ ] 用标准仪表对照 0/1.8/3.3/5/12/24/30V，按多个温度/供电状态测出实际误差后标注性能。

### 3.5 F19｜蜂鸣通断

- [ ] `VΩ/COM` 同一对表笔用于通断，但与正常电压测量路径的电流注入功能严格隔离。
- [ ] 采用限流、硬件默认 OFF 的测试激励，不允许 GPIO 直接推 3.3V 到表笔。
- [ ] 在切换通断前先检测外部带电，并拒绝启动；**软件拒绝不能替代硬件过压/误接保护**。
- [ ] 目标：短接和低于约 50Ω 稳定鸣叫，1kΩ、断线/开路不鸣叫；阈值/响应按样机校准。
- [ ] 在 ESP32 重启、关机、OTA、失电、按键误触和外部 +5/+12/+30V 误接下，激励不能向内部倒灌使元件超限。
- [ ] 复用原有 BUZZER1，支持关闭提示音、避免与报警音互相混淆。
- [ ] 说明书强制注明：**通断仅用于断电线路**；设备与电脑连接时仍可能共地。

### 3.6 F20｜智能电源、图表及数据记录

- [ ] 电压档位预设、细调/快速调节、限流上限、输出开关、告警、故障历史。

- [ ] 数据记录可由手机/电脑缓存和导出 CSV；本机存储空间按 OTA/动画素材空间预算设计。
- [ ] 远程开启可调输出的鉴权和设备本地最终裁决；失联时遵守明确的安全策略。

### 3.7 F21/F22｜无线工具箱与桌宠

- [ ] Wi-Fi 扫描：SSID、信号强度、加密类型（由 API 实际能力决定），不扫描/展示敏感私人流量。
- [ ] BLE 发现：广播名称、RSSI、设备标识及可公开读取的广播字段；控制扫描周期以省电。

- [ ] 离线桌宠运行不需要 AI 云端服务；如未来增加联网 AI，属于另行规划的非第一版功能。

- [ ] ESP32：无线 UART 的目标 TX/RX 和无线下载器要求的目标 BOOT/RESET/下载口。

- 不能为了无线下载器，假设没有连线的两个 MCU 会自动交换下载数据。
- 不能为了省连接器引脚，把 VΩ 表笔、VOUT 电源、逻辑分析、SWD 高低电平线直接混用。

## 6. 整板 BOM 物料统一采购规则（项目刚性规则）

> 目标是**减少不同的采购料号**，而不是单纯减少焊点数或让阻值机械地相同。两块四层板要放在一张总采购清单中分析。

### 6.1 BOM 生成与合并

## 13. 已明确取消的硬件及不能误宣称的能力

### 13.1 本版本不增加

- [x] 不增加 ESP32↔RP2040 的新 SPI 通信线路。
- [x] 不增加独立的 USB 5V 升压、USB Host 5V 对外供电、固定 5V 端子。
- [x] 不增加 MPU-6050、AHT20、外加 MAX17048、环境光传感器。
- [x] 不新增 VTREF 检测与八路 SN74LVC541A 缓冲保护（原有保护仍需审查）。
- [x] 不增加红外、振动马达、扬声器、麦克风、额外 RGB 娱乐灯。
- [x] 不添加 SD 卡、额外主控、第二颗 INA226、专用 16 位外部 ADC，除非未来正式修订需求。

### 13.2 不能直接对外宣称

- 未经测试，不宣称任何输入可接 220V 市电、交流、负压或任意浮地差分。
- 不承诺 3.3~20V 全量程连续 3A 或电池驱动高压大功率输出。
- 不承诺逻辑分析 8 路输入天然 5V/12V 容忍。
- 不承诺 DAP 支持所有 ARM/RISC-V 或所有 CMSIS-DAP 上位机。
- 不承诺简单示波器的高带宽、高采样率或微秒级电流尖峰检测。
- 不承诺无线下载器支持任意 MCU 或“无需物理下载线”。
- 不承诺现有 USB HUB 自动使 ESP32 获取 RP2040 八路实时数据。
- 不承诺手机/电脑 App、动态桌宠、OTA 因硬件存在便已完成；均需单独软件开发与验收。
