## 1. 项目一句话与目标

EXLINK PRO 2.0 是**小型方形、带触摸屏、锂电池的便携式嵌入式多功能调试器**，用于 STM32/ESP32/智能车/机器人等开发现场。它结合 USB 下载调试、8 通道逻辑分析、串口、工具信号、智能可调供电、独立低压电压测量与断电通断检测，配合手机 App 和独立 Windows 调试软件。

**优先级：电气安全和原功能完整性 → 小体积/可制造 → 稳定性和性能 → 续航 → 降 BOM 成本/料号数量 → UI/桌宠可玩性。** 近期用户更强调“**成本低、性能不减、器件尽量少**”，但不能因省料牺牲安全或可靠性。

**工作方式**：用户在**嘉立创 EDA 专业版**亲自绘制两板原理图、已完成主要布局布线，继续亲自修改与调试。Agent 提供独立工程判断、官方资料依据、具体引脚/元件/连线建议和截图审核；用户希望按**连续小模块一次推进较多内容**，不要每根线都单独一轮；已经确认的电路不要没有充分理由反复推翻。

**边界**：不要混入用户的第 21/22 届智能车、签到助手、招聘插件等其他项目。EXLINK Studio 虽可脱离硬件独立运行，但它是本交接中唯一需要一并描述的软件产品。

### 3.1 两块 PCB 和结构

- **PCB-A：功率/主控板**。ESP32-S3R8、16MB Flash、USB-C/PD、输入保护、电池充电、电源路径/3V3、MP28167/MP5016/INA226、测压与通断模拟前端、屏幕/触摸、RF、按键/蜂鸣。
- **PCB-B：调试信号板**。RP2040/外部 Flash/晶振/BOOTSEL、CH549G/ISP/DAP/WCH/USB CDC、八路逻辑输入/保护、外部调试口与排针、必要 USB 数据链。
- **结构**：功率板四层、信号板双层，双面贴装、叠板。最近讨论的板尺寸约43×37mm，空间非常紧。此前 STEP 模型 `上盖盖1014.STEP`、`底座座1014.STEP` 分别外包围约46.5×46.5mm，整体高度约20mm，**旧分析指出两 STEP 按原坐标直接叠放存在干涉**。必须重新以可用 STEP、真实 LCD、电芯、USB-C、接口、FPC折弯、天线净空完成 3D 机械核验。
- **屏幕**：正式选型 KD021WVOSN009-C003B，2.14英寸 AMOLED，480×480，CO5300AF/CST9220，24Pin QSPI。电气脚序本轮审查对应，CN2公母机械配对仍待确认。
- **电池**：1S 800～1000mAh 是 V4.9 仍可参考的容量方向，但请核用户最近实物选型、保护板、NTC、线序、尺寸，不写成已采购。
- **不随意改板数**：维持当前双板、四层＋双层，暂不擅自加第三板、改6层或扩尺寸；若真实布板不下，要有基于封装面积/3D/接口的证据再与用户讨论。

| GPIO18、21 / 物理24、27 | 触摸内部I²C SDA/SCL | 与MP28167/INA226等内部总线是否共线需核 |
| GPIO19、20 / 物理25、26 | ESP USB D−/D+ | 与CH334 USB下游实际连接待验证 |
| GPIO33～37 / 物理38～42 | 封装内Octal PSRAM使用 | **不可作为空闲GPIO/ADC** |
| GPIO38、39、40 / 物理43、44、45 | 五向摇杆RIGHT/LEFT/PUSH | 保留 |
| GPIO41 / 物理47 | VCI_EN | 屏幕供电使能 |
| **GPIO42 / 物理48** | **CONT_EN_N** | 11-25审查记录；低有效、默认OFF待验证 |
| GPIO43、44 / 物理49、50 | ESP32_TX/RX | 串口，具体与外部接口关联待查 |
| **GPIO45 / 物理51** | **LCD_TE** | 11-25审查记录；启动绑带与屏幕运行中单独复位待验证 |
| GPIO46 / 物理52 | R1 100k 下拉 | 绑带脚，不当普通安全控制GPIO |
| GPIO47、48 / 物理37、36 | QSPI_D2、QSPI_D3 | 屏幕 |

**原11-13高优先级未接网络（历史状态）**：`VM_ADC_IN`（测压ADC）、`CONT_ADC_IN`（通断ADC）、`CONT_EN_N`（低有效使能）；11-25审查记录 VM_ADC_IN=TLA2528 pin15、CONT_ADC_IN=pin16、VM_ADC_EN=pin1、CONT_EN_N=GPIO42；仍以最新网表及实测为准。`CONT_EN_N`经R21 10k上拉，应默认禁用激励；`VM_ADC_EN`经R20 100k下拉，目的为默认禁用模拟开关；控制脚的低/高有效关系需同具体芯片真值表核实。

**原始RF修改**：`C3=1.5pF、L2=2.4nH、C34=1.5pF` 是用户批准的首板候选参数，不等于通过VNA实测的50Ω匹配。

## 6. 安全、质量和“不擅自恢复”清单

### 6.1 设计红线

- 表笔`VΩ/COM`与可调供电`VOUT/GND`、逻辑分析、SWD接口分离，COM为**共地非隔离**；不能直接接市电或未验证的交流/浮地电压。新目标含负压，但**尚无负压保护/测量通过证据**，外部使用限制须在验收后更新。
- 通断仅针对**已断电电路**；检测激励在关机、重启、OTA、GPIO浮空、低电量时由硬件默认OFF；带电误接不能只靠软件禁止。
- 不能把可调输出的INA226当成独立外测电压表，也不能用慢速VΩ采样假冒示波器。
- 充电/PD要覆盖弱电脑USB5V与独立12V PD：协商到12V不等于同时有PC主机数据。输出VOUT在弱USB模式默认OFF；电池模式不直接承诺PD功率外部输出。
- 上电/复位/OTA时VOUT默认OFF。MP5016H U10的MODE/OVP配置与20V目标可能冲突；外部电源反灌、电感/电池高温、低电量、过压/短路与故障日志必须审查。
- 逻辑分析8通道输入电平、DAP兼容目标、WCH模式、无线下载协议、示波带宽都必须**实测后才可对外宣称具体性能**。
- 各类电阻/电容优先复用**完整厂家或LCSC料号**，并核对封装、功率、耐压、精度、温漂、介质；不能仅因同为10k就合并。INA226分流实际 20mΩ / ≥0.5W / Kelvin 需核。
- 任何新芯片或跨板导线先评估安全、占位、GPIO、软件与BOM。维护BOOT/ISP/USB/FPC/天线净空优先于美化。

### 6.2 历史明确排除（若后续实际工程/明确决定改变，应做变更记录）

**长期排除**：不新增ESP32↔RP2040专用SPI；不增加独立USB 5V升压、USB Host 5V对外输出及固定5V输出端子；不额外加MPU6050、AHT20、MAX17048、环境光、红外、麦克风、扬声器、振动马达、额外RGB；不新增第二颗INA226、新MCU、SD卡、SN74LVC541A八路缓冲、VTREF检测；不把屏幕随便更换针脚；不使用大型继电器来切换测压/通断、不把测量模块移到B板；不新增重复TP1、不擅自给GPIO0加10k上拉、不机械堆加无需求的去耦电容。

**存在后续版本冲突**：ADS7138仍无采用证据；**TLA2528在11-13被否决、11-14又出现在U5的工程讨论**。必须按最新原理图确认最终决议，不得把过往否决原封不动当成现行禁令，也不得在未验收时称其已成功工作。

## 8. 主机固件与通信架构

### 8.1 控制器职责

1. **ESP32-S3R8**：建议ESP-IDF + FreeRTOS + LVGL；屏幕/触摸/按键、功率与充电状态、电压/通断测量、Wi-Fi/BLE、桌宠、设备协议、事件/日志、ESP32 OTA；参考原开源固件的 Arduino_GFX/CO5300、CST9220和内部I²C服务，**参考实现 ≠ 已完成移植**。
2. **RP2040**：8路逻辑采样、PIO/DMA缓冲、USB上传，保留BOOTSEL/UF2恢复。电脑逻辑分析可独立使用；不新增与ESP32的SPI。
3. **CH549G**：原博主DAP/WCH-Link/USB串口固件和ISP维护，需逐目标MCU确认烧录、SWD单步、各驱动模式和USB枚举。
4. **CH334F**：仅USB HUB芯片，负责PC上游汇聚多个USB下游，**不提供设备间共享内存或自动联通两颗MCU**。
