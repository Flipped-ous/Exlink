# S1-04｜日志与系统诊断详细设计 V0.1（用户确认）
2026-11-26。仅详细设计归档；目标实施分支嵌入式固件。S0-06A完整审查证据及其余技术验证仍待闭环；未授权正式实施、修改Flash分区、真实硬件驱动或烧录。

## 职责与边界
统一轻量日志接口服务业务、驱动及系统模块；日志等级、时间戳、模块标识和错误信息集中管理。有界RAM日志缓存，设置→系统诊断、授权电脑/手机及独立USB调试输出按需读取。重要故障限量持久化；Safety故障锁存及紧急关断独立，日志关闭、缓存满、持久化失败不影响安全保护。沿用S0-11/12/16/17及S1-03，不重复状态仓库、存储协调或安全控制。不引入额外第三方日志框架，优先使用当前SDK已有API，具体适用性待验证。

## 等级及接口
DEBUG（开发调试，默认关闭）、INFO（启动/连接/状态变化，开启）、WARN（超时/重试/资源不足，开启）、ERROR（硬件/系统异常，开启）。LOG_I("System", "Boot completed")、LOG_W、LOG_E等为接口示意，非锁定API。内部标签/代码允许英文；所有用户可见诊断文案中文。不得在高频ADC采样中断、每次PWM更新或每帧UI刷新中打印，采用有界计数器；避免实时路径格式化、大内存分配、阻塞串口/网络/Flash及长临界区。系统日志、用户原始UART数据和管理协议明确隔离，USB调试输出须核对实际通道归属，不占用目标UART或混入协议数据。凭据、密钥、配网密码及敏感载荷不进入日志。

## 存储与读取
| 内容 | 初始候选策略 |
|---|---|
| 普通运行日志 | 8KiB RAM环形缓存 |
| 调试日志 | 按需开启 |
| 重要故障 | 最近16条有限持久化记录 |
| 异常复位 | 少量持久化记录 |
| OTA | 最近升级结果 |
| 长期日志 | 手机/电脑保存 |
8KiB和16条为候选预算，实际容量需内存、并发及NVS磨损测试，不冻结生产参数。不新增Flash分区，不另建重复持久化任务。缓存满覆盖最旧完整记录，记录丢失/截断统计；多任务安全，短临界区，单条记录长度有界。各授权读取端有独立游标，读取不消费全局缓存；落后时报告缺失，不承诺无损补传。时间戳使用可靠运行时基准，区分启动会话；没有有效绝对时钟不伪造日期。重要故障去重合并、限频、限量，普通日志/采样不写Flash；采用S0-16统一非实时写入协调，OTA暂停普通持久化。异常关机可能来不及保存，不承诺所有掉电前日志可恢复；复位原因以SDK真实记录为依据。

## 后台诊断及界面
- 系统：固件版本、运行时间、复位原因。
- 内存：内部可用堆、最小剩余堆、最大连续块、PSRAM。
- FreeRTOS：任务栈高水位、必要任务运行状态。
- 内部I2C：超时、失败、恢复计数；示波器：采集异常、缓冲溢出。
- 通信：连接、丢包、队列溢出；电源：安全锁定及最近故障；OTA：版本、最近结果及回滚状态。
优先复用现有维护模块低频更新及按需获取快照，不增加高频常驻诊断任务。设备设置→系统诊断包含系统状态、内存状态、屏幕/触摸、内部I2C、电源、INA226、TLA2528等硬件状态，以及运行日志、历史故障、重启记录、诊断导出。未初始化、未验证、失联、过期及模拟状态明确区分，不能默认全部正常；安全告警独立于页面。电脑/手机经授权读取，按S1-09批准协议定义线级格式，当前不冻结。示意UI和数值不是实测或最终视觉设计，S4统一评审。
