## 简易示波器（S3-09）
单通道低速模拟采样，GPIO4/ADC1_CH3为核查基准；不使用TLA2528慢速VΩ测压或INA226替代原示波采样。实时波形、暂停/继续、水平时基、垂直刻度、自由触发、上升沿/下降沿触发、频率/峰峰值/平均值测量。无可靠触发或有效采样时显示不可用/失效，不编造测量值。独立按需采集与有界缓冲，UI刷新不决定采样率，暂停语义、触发电平、测量窗口及实际采样/带宽/量程待测试和UI细化。ADC1与GPIO2电池采样协调，低电量保护及有效性不能牺牲；停止确认DMA/IRQ/回调与资源释放。会话中的600Hz、3.3V、时基及波形均为模拟展示，不是硬件规格。

## PWM信号发生器（S3-07）
频率、占空比可调，支持常用参数预设、设定波形预览、独立输出开关。预览不代表实际波形；上电、复位、OTA及安全停止后默认关闭，预设加载不自动开启。GPIO5/LEDC为候选；3.3V逻辑IO为硬件设计方向，实际电平、频率范围、分辨率及占空比边界需SDK/电路验证，不增加可调幅值功能。演示中的100Hz/1kHz/10kHz/20kHz及0～100%仅交互示例，不冻结参数。使用与蜂鸣器独立的LEDC通道和定时器，真实启停及配置错误反馈，不假设写入成功。

## 数字频率计（S3-08）
频率、周期、最大/最小/平均统计，Hz/kHz/MHz自动单位显示；MHz单位不表示已支持MHz输入。GPIO5/PCNT候选，门控/计数溢出、无信号、数据有效性、周期换算及统计按实际可用测量确定；无有效频率时不显示虚假周期。实际输入电平、上限、精度和保护待验证。

## 资源与安全
PWM与频率计共享GPIO5互斥（最终网表裁决），默认拒绝冲突；用户确认停止旧功能后才安全切换，避免外部驱动争用。示波器与PWM/频率计、数控电源、万用表原则允许申请并行，不保证全部组合；受资源、功率和电气安全限制。沿用S0-10/15及S1-06，独立退出停止所属业务，工作台切换不停止已运行组件、移除/结束安全停止。OTA受控暂停，危险输出不自动恢复。输入耐压、前端、GPIO映射、真实并发与保护待最终网表/样机确认；不修改PCB。
