# S5-03｜公共通信协议设计 V0.1（用户确认方向）
2026-11-26。依据S0-14、S1-05/09、S5-01/02。四工程ESP32、Studio、Mobile、Simulator共用一份协议及测试向量；Simulator为独立虚拟设备服务端，不是实际硬件中转。用户确认总体方向及三端权限修订，常规字段、错误码、测试向量可由ChatGPT统一设计审查，重大功能和安全变更仍需用户决定。未冻结完整线上schema，未授权S5实施。

## 传输与消息
WSS/HTTPS及BLE GATT为已确认技术方向的候选实现，依S5-01/02安全及兼容验证。控制、状态、事件、低速测量用JSON；示波器采样、UART原始字节和OTA用有界二进制，分帧、流控、端点/UUID待S5-04/05细化。独立RP2040/CH549原生USB协议保持，不假设ESP32转发。hello（版本、能力）、cmd、result、state、telemetry、event六类消息为设计候选；认证前仅必要发现与受限配对信息，不能泄漏业务状态。
示意（非最终线上规范）：
cmd {"id":1001,"type":"cmd","method":"power.set_voltage","params":{"voltage_mv":5000}}
result {"id":1001,"type":"result","code":"OK","data":{"target_mv":5000,"output_enabled":false}}
设置目标不等于开启输出，接受、执行、实际测量分离；冲突状态版本检查字段须在正式schema定义，不能直接将示例作为完整可发送命令。

## 统一物理量与模块
候选整数单位mV、µA、µW、Hz（小数频率精度待编码细化）、0.01%占空比、ms；有符号测量，范围/位宽及溢出测试统一，不得以无效值置零。时间基准、boot/session标识、有效性、状态revision与数据序号待详细定义；配置修改版本与高频遥测更新须区分，避免正常采样导致所有控制冲突。
device、power、meter、continuity、scope、pwm、frequency、i2c、uart、workspace、wireless、settings、ota、diagnostics为候选模块。保留既有S0-12错误语义；各端中文错误映射，不自行定义不兼容命令。

## 三端控制（用户补充）
Safety独立安全裁决优先于所有操作；本机最高操作优先级；Studio与Mobile同级，不设置远程主从或全局锁。优先级不同于功能权限，Mobile仅基础控制，Studio支持经确认的专业控制。远程控制须完成安全配对、当前有效连接及认证、能力与权限校验后开放；默认不额外增加每次连接手动开关，具体交互后续确认。断连禁用控制、标数据过期、取消失效待执行请求，不重放旧命令；普通断连不自动关闭正常输出。设备同步各端权威状态和结果，不保证不同界面同屏或毫秒级一致。
同服务串行执行；本机冲突操作优先，取消未执行的对应远程冲突命令；已执行或在途操作不可假设可强制中断，按安全生命周期处理，关断与Safety优先且迟到结果不得重新开启。两个远程端平级，校验预期控制版本，拒绝过期修改。权限与客户端类别/能力由设备可信授权记录及会话绑定决定，不信任自报类型、不仅靠隐藏界面，未经批准禁止扩大Mobile授权。通断远端只读；OTA需确认及维护互锁；工作台归属和资源互斥沿用既有方案。本机优先不绕过硬件限制。

## Mobile范围
用户明确减少控制功能、仅基础控制，不复制Studio。具体功能白名单在S6-B单独确认；电源基础调压/启停/预设、实时数据、PWM基础调节、轻量查看/串口、维护为讨论候选，不视为本轮批准的完整清单。高级时序、寄存器调试、专业波形及复杂工作台等是否开放待S6-B，未批准控制默认拒绝。保留既有记录、桌宠及OTA维护方向，不擅自取消；Studio独立通用串口/USB工具不受EXLINK无线配对要求影响，EXLINK设备管理必须配对。

## 可靠性与管理
同一认证会话内请求ID去重及结果信用；超时查询、不得盲重放；严格长度、类型、范围、权限、版本及能力校验，有界队列/缓冲，独立安全路径。协议统一入口protocol/device-protocol.md，候选commands.md、error-codes.md、schemas/、test-vectors/按需创建；本轮不创建未冻结schema或假测试数据。S1-09仅已授权内部语义/草案，不私定线上协议。最终版本、端点、分帧、认证、字段范围、序列化和跨语言测试须闭环。
