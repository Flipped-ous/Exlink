# S5-02｜设备配对、鉴权与多端控制 V0.1（用户确认）
2026-11-26。依据S5-01 V0.2、S0-14、S0-13、S1-05/09。可靠性优先，首次本机授权、后续认证重连，设备权威，不引入账号、云服务器、手动IP或复杂角色体系。仅设计确认，未授权S5实施；具体安全握手、依赖及生产参数未冻结。

## 配对及信任
手机BLE发现，电脑可通过BLE、mDNS或设备AP自动发现；无蓝牙电脑仍须安全首次授权。连接申请由本机确认，示意六位配对码须与标准安全握手及双方身份绑定，不是任意提示数字，不把Just Works、设备名、MAC、IP或热点连接视为授权。配对模式、窗口及失败限频按安全验证确定；不开放无期限授权、不默认明文凭据，不绕过证书校验。发现仅公开必要的非敏感信息。首次安全配对后保存各客户端独立可信凭据，后续自动认证，普通操作不反复弹窗。设备设置内查看/移除绑定，解除绑定使对应凭据、连接和未执行命令失效；正常已执行输出遵循既定Safety及会话策略，不把解除绑定混同于物理关断。重置连接与身份恢复按S0-16，凭据及密钥不进入普通日志、导出、仓库。
配对交互示意非最终UI；S4暂缓。

## 权限
未授权设备仅发现及发起受限配对，不得读取业务数据、调整参数、开启输出、串口发送或升级。可信设备允许读取及经设备安全/资源/能力核准的仪器控制和串口收发；远程通断首版只读，本机开启；OTA需明确用户确认及独立签名、维护互锁（S5-05细化），不能由信任绑定直接触发。无额外管理员/访客角色。权限在可信入口及执行前校验，不能依赖UI隐藏或客户端自报身份。

## 多端控制及异常
本机、手机和电脑可同时读取；按业务服务串行化修改，校验预期状态版本，拒绝过期冲突操作。设备权威状态同步各端，目标参数、真实测量及执行结果分开。不引入全局单客户端锁；实际连接数、内存及负载待验证。Safety独立紧急关断，本机及授权关闭优先并取消失效开启命令；普通断连不自动关闭正常输出，取消未执行失效请求，重连认证后读取实际状态，不重放危险命令。OTA锁定危险操作，故障解除保持OFF。工作台资源与会话所有权按既有设计，不能因可信绑定越权释放其他会话资源。实际物理关断未证实须标未确认。

## 技术候选及验证
优先既有SDK Bluedroid支持防中间人攻击的配对方式、WSS/HTTPS、mbedTLS、设备端NVS保护方案与客户端操作系统安全存储。普通NVS不天然加密，设备身份、证书信任、跨传输首次配对及凭据保护须实际验证，不自造密码学，不允许明文或禁用验证作为失败回退。密钥生命周期、撤销、配对码安全性、认证时限、会话数及握手资源开销待验证；未经授权不烧eFuse。可靠性与安全性未满足不得启用远程危险功能。技术候选非正式冻结。
