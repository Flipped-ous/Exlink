## 产品定位和界面
独立电脑端本地研发/测试工具，与EXLINK Studio分开维护，不是正式产品必装软件。无需自建服务器，不强制付费模拟软件。EXLINK Virtual Device为界面示意称呼，沿用仓库EXLINK Simulator及现有目录，不因此强制改品牌或目录。
左侧480×480设备界面优先直接复用未来真实固件的LVGL页面及可移植业务；右侧虚拟硬件环境、故障控制和运行日志。可通过鼠标等主机输入模拟触摸/按键；实际页面布局、视觉、交互细节在后续UI阶段评审。所有用户可见内容简体中文并明显标识模拟，示意图不是最终设备首页。
独立轻量协议模拟服务先为Mobile和Studio提供联调环境；固件级主机模拟为目标，不将两者混淆为完整真实固件。两者共用经批准的设备协议、能力及测试向量；PC固件级尽可能复用C/C++核心和真实LVGL页面，轻量协议模型不强制跨语言绑定。模拟设备身份、发现入口及测试数据与实物分离，故障注入入口只存在于模拟测试环境，不进入生产设备协议；模拟器不得驱动真实危险硬件。

## S2任务及验收
| ID | 实施范围 | 验收方向 |
|---|---|---|
| S2-01 | 官方LVGL PC Simulator可行性探针，匹配最终LVGL版本，SDL2/CMake候选，主机显示/输入/时钟适配 | 实际构建运行480×480窗口，记录依赖/许可证/运行命令；后续复用真实页面，不另造完整UI |
| S2-02 | 本地轻量协议模拟服务，Python/asyncio候选 | 共享S1-09批准的协议及向量，独立模拟身份、连接、命令/结果/快照/重连；Mobile/Studio实际联调 |
| S2-03 | 虚拟硬件模型及Mock HAL衔接 | 可重复输入、状态、单位、有效性、资源冲突及安全拒绝；不伪称物理精度 |
| S2-04 | 故障注入、环境控制及日志 | 正常/异常可重复切换，故障关断、数据失效、恢复不自动启动；测试入口隔离 |
| S2-05 | 自动化回归及分层验收 | 记录实际命令、版本、日志、失败和未执行项；用户体验验收另列 |
S2-01/02可并行准备；协议模拟服务优先供客户端联调，但不得在S1-09尚未统一线级协议时私定生产协议。先最小探针/无界面场景，再增加真实LVGL页面、硬件模型、故障、自动化回归；S3业务及S4页面可逐步接入，不等待所有实体硬件。实际开发另行授权。

## 模拟功能
| 功能 | 模拟场景 |
|---|---|
| 数控电源 | 输入供电、目标电压、输出开关、虚拟负载、V/I/P |
| 电压表 | 正负电压、过量程、无效数据 |
| 通断检测 | 导通/断开、外部带电/未知拒绝激励；远端只读 |
| 示波器 | 正弦、方波、三角波，独立有界采样缓冲 |
| PWM/频率计 | 频率、占空比、互斥及释放 |
| 外部I2C | 虚拟从机、NACK及超时 |
| 串口 | 模拟收发、原始字节及有界流控 |
| 联合工作台 | 多工具组合、切换不中断、移除/结束安全停止所属资源 |
| OTA | 模拟升级进度、失败、激活及模拟回滚，不写真实设备 |
| 电池 | 模拟电量变化、低电量条件 |
固定种子、注入时钟、明确测试场景；短路、过压、I2C异常、过期测量、断连、重复命令、配置损坏、缓存溢出、OTA失败与资源冲突等覆盖正常/异常流程。所有模拟参数、负载和保护阈值仅为测试模型，不冻结生产电气参数，不以模拟证明硬件真实保护、ADC精度、带宽、USB/RF、功耗、温升或Flash掉电回滚。
