# S3-D｜调试工具功能设计 V0.1（用户确认）
2026-11-26。对应F01–F05、F08、F13/F14及S3-10/11/12/15/16；USB HUB实物验收归S7。依据R4统一来源、source-audit.md、studio-integration.md及protocol/device-protocol.md。优先保留原版成熟功能，不新增硬件、不强制重写成熟固件。仅功能设计确认，未授权实施、烧录或发布第三方固件。

## 外部I2C（S3-10）
保留地址扫描，增加指定地址寄存器读写、HEX数据及通信错误提示。外部总线GPIO6/7为核查基准，与内部电源/触摸总线严格隔离。扫描不擅自修改目标寄存器；写入由用户明确执行。地址及保留地址处理、寄存器地址宽度、重复起始、事务长度、总线速率和电平按目标协议及实际硬件验证，不承诺任意设备兼容。示意中的100kHz、0x3C/0x68不是实际扫描结果或冻结参数。

## 串口（S3-11）
支持波特率、实际可用串口格式、文本/HEX收发、换行设置、接收计数、暂停显示、常用发送指令；保留原始字节，显示暂停不等同停止接收，有界缓存及溢出统计。长时日志、数据解析和波形绘制优先由Studio承担。有线CH549 USB CDC与ESP32 BLE/Wi-Fi目标UART桥接分别维护，不假定二者互通；GPIO43/44与实际目标UART连线、USB CDC TX/RX及电气条件待核。沿用公共协议、授权、会话、队列和资源冲突机制；不把目标串口数据与设备管理/日志混发。示意中的115200/8N1仅示例，实际支持项待测试。

## 无线下载（S3-12）
保留原版功能追踪，先查真实BOOT/RESET/下载信号、GPIO11/12/13归属、目标协议及参考实现，按经过验证的目标芯片开放。无线下载不等同ESP32自身OTA，不保证通用无线SWD或任意芯片支持；未知线路/协议时仅模拟或标记不可用，不能假装成功。不新增跨主控连线。

## 独立USB工具（S3-15/16及F05）
- RP2040：保留8通道逻辑分析，独立PIO/DMA及USB采集上传；优先调查可授权的sigrok兼容源码与PulseView联调，保留BOOTSEL/UF2恢复路径。Studio规划波形及I2C/SPI/UART协议解码，具体实现归S6-A详细设计；不要求设备小屏显示完整8通道波形。采样率、输入电平、缓冲及解码支持待实测。
- CH549G：保留DAPLink/ARM SWD下载及在线调试、WCH-Link经验证的沁恒目标、USB CDC有线串口。模式、驱动、目标型号、实际接口和ISP恢复待验证，不承诺全RISC-V或所有模式同时可用。优先合法复用或适配，不以二进制存在证明源码或分发权。
- CH334F HUB：汇聚电脑上游及多个独立下游USB设备，核查三路枚举、供电与并行传输。HUB不是ESP32/RP2040/CH549之间通信总线；不新增ESP32-RP2040 SPI，不假设ESP32能控制或读取独立USB调试器。ESP32的USB管理能力以真实连线和SDK为准。
- 设备端可提供实际可用工具及接口说明；电脑端Studio与成熟外部工具按真实协议连接。未验证能力标为不可用，不显示虚假连接或调试状态。
