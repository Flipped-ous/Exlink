# S3-B｜测量系统功能设计 V0.1（用户确认）
2026-11-26。对应F18/F19、S3-05/06；F12原版电压表整合仍保留追踪。依赖S3-01内部I2C和S3-02 Safety；仅功能设计归档，不授权实施或真实测量/激励。依据R4统一来源、firmware-safety.md、firmware-resources.md、firmware-ui.md、S1-02/03/05及S2。

## 功能及交互
首页合并为一个“万用表”工具，首版仅直流电压、通断检测两种互斥用户模式，不增加交流、电阻、电容或独立电流表功能。名称不意味着完整万用表或市电测量能力。共用VΩ/COM表笔，非隔离共地，与VOUT/GND和INA226输出检测分开。
| 功能 | 确认方向 |
|---|---|
| 直流电压 | 正负电压，目标-20～+20V，3.3V附近准确度目标±0.1V |
| 自动量程显示 | 用户无需手动切换档位，按实际范围显示；不承诺硬件多量程自动切换 |
| 实时曲线 | 低速电压趋势，不替代示波器 |
| 数据统计 | 最大、最小、平均值，基于有效采样 |
| 数值保持 | 暂时冻结显示值，明确保持标志，不停止后台安全监测 |
| 通断 | 导通/未导通及蜂鸣反馈 |
| 带电保护 | 带电或状态未知拒绝激励，持续安全监控 |
| 远程查看 | Mobile/Studio同步测量结果，首版远端通断只读 |
界面示意为可交互Mock，不是最终UI、真实采样或保护性能。蜂鸣静音仅作用于普通通断提示，不关闭必要安全告警；实际提示样式待S4。测压数值、曲线、统计及保持值区分有效/过期/过量程/通信错误，不把未知值当0V。通断结果在数据失效时不显示正常未导通。具体低阻阈值、蜂鸣响应、滤波和采样速率、统计窗口及精度由电路和测试确定。

## 硬件和安全
TLA2528为现行设计候选，实际芯片、模拟前端、网表、控制脚真值表需核。R4记录VM_ADC_IN=TLA2528 pin15、CONT_ADC_IN=pin16、VM_ADC_EN=pin1、CONT_EN_N=GPIO42低有效且10k上拉；仅核查基准，不能未经确认直接驱动。旧前端初始为0～30V正压，新±20V目标的偏置、负压保护、误接、静态漏电及反供电未证明。目标不是额定耐压，不允许市电或未验证的浮地/交流测量。
通断仅用于已断电电路，默认激励关。进入模式后须本机明确操作并满足Safety授权、有效带电检测及硬件保护条件才可启用；模式切换、退出/移除、复位、OTA、必要低电量、带电/未知或保护故障禁用激励，不自动恢复。激励期间必须区分自身激励与外加电压，不使用保持/滤波显示值代替安全判据；实际独立关断及误接保护未验证前不启用真实通断。测压与通断用户模式互斥，不妨碍内部安全检测；工作台及远端不可绕过限制。软件禁止不替代硬件保护。内部I2C单一事务所有者，TLA2528不占ESP32内部ADC1。F12不得删除或重复实现：核对旧外测口与新版表笔信号、功能及实际能力，再决定整合映射。
