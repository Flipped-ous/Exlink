## 4. 必测细节
- IPC保留主进程可信sender/mainFrame验证、contextIsolation与sandbox、禁用nodeIntegration、禁止不受信任导航；输入类型/长度/端口/配置/身份校验，禁止任意IPC/文件或系统命令入口；隔离旧连接generation，退出/崩溃清理不泄漏句柄，stop超时/失败真实暴露。
- 发送队列独立、有界；并发发送顺序明确，关闭/拔出/失败不把旧指令发送到新连接。TX时间戳是主机发送尝试时间，不等于物理线上首字节时间；单调序号区分同毫秒事件；write/drain不等于目标ACK。旧导入记录缺少新字段时兼容读取，不捏造历史状态。
- 内存预算分别统计原始有效字节、记录/索引/解码缓存、数值缓存、IPC及冻结视图，不宣称8MiB总堆；typed array若引用大底层buffer须计算实际保留量。分片UTF-8与协议解析不因显示缓存损坏原始记录；缓存按记录淘汰/源销毁释放，跨源总预算、慢消费者及丢失标记需测试。保留峰值/缺失的波形显示策略。
- 性能基准同机器、同构建模式、同输入种子/速率/时长/连接数、相同可比交互；至少单源及双源的115200/921600等效可重复模拟数据场景（不是实际串口吞吐保证）、空筛选/文本/HEX筛选、持续接收/暂停恢复、反复打开关闭、慢消费者。记录输入/处理/丢弃字节/记录、UI刷新及延迟、CPU、主/渲染进程heap/RSS/外部Buffer趋势、峰值及回收。明确统计方法与样本，若无可比基线不声称提高百分比；给出可验证实测预算候选，不任意冻结性能指标。
- CI使用现有测试和新增测试，保留离线演示及真实串口可用性，真实COM回环/物理拔插及EXLINK实物依设备条件单列。测试必须真实执行，不伪造结果。
