# S5-04｜实时数据传输与断连恢复 V0.1（用户确认）
2026-11-26。用户指出三端并发可能堵塞和延迟，确认本机+Studio为主要调试组合，Mobile仅辅助、按需连接，保留三端兼容及全部可提供业务数据查看；不将三端满负载作为常态。可靠性优先，后续按实际需求调整。仅设计归档，不授权实施。

## 传输和负载管理
- 安全保护、采集、硬件服务及本机交互独立于网络发送；Safety独立关断及锁存，故障通知优先但不承诺网络实时送达。命令接受前预留终态结果信用，拥堵时明确拒绝/超时查询，不静默丢弃或盲重发。
- 单次采集及共享有界快照/采样缓存，按需订阅，客户端独立发送进度、有限缓存/引用生命周期；慢客户端不得长期占用共享缓冲或阻塞生产者。网络任务异步处理，不持业务锁等待I/O，不阻塞LVGL或ADC。控制/状态及高频二进制流分别调度；是否独立WSS连接、分帧、最大帧/发送时限及TLS开销待验证，不把逻辑隔离当作物理带宽保证。
- 状态变更同步；低速遥测可合并最新值，波形/串口按需批量传输，诊断按需读取。波形预览降帧/降采样需保留实际单位、采样信息、序号及缺失标识；原始UART字节流不可伪造连续性或静默降采样，过载明确报告缺失。停止订阅不自动停止业务或启动采集。独立USB数据路径仍待核。
- Wi-Fi主用；正常Wi-Fi会话不通过BLE重复推送同一业务流。共享射频、TCP队首阻塞、TLS堆及CPU竞争均需实际验证。过载先合并低优先级遥测、降低预览速率，再暂停高带宽订阅或断开持续阻塞的会话；恢复重新同步，控制与保护优先。OTA独立维护互锁，暂停冲突数据流。

## 主要双端与辅助手机
本机独立运行，Studio是持续专业调试主用端；Mobile不默认后台长连或持续收数，打开工具才订阅，退出/后台停止非必要传输，高频波形默认低负载预览。明确用户授权的维护过程另按S5-05处理，不因进入后台而假称OTA成功或自动恢复输出。手机仍可查看全部实际可提供业务数据，基础控制白名单待S6-B；手机与电脑操作优先级平级，本机最高，Safety独立。带宽资源不足优先保证本机与Studio数据体验，不因此降低手机控制命令权限或跳过安全处理。三端同时连接保留，常态优先本机+Studio；Mobile开发/联调后置于核心双端，具体实施授权另行确认。
初始测试候选：电源本机显示10–20Hz、Studio推送10Hz、Mobile推送5Hz，万用表5–10Hz、电池1Hz、PWM配置变化推送、频率计按门控、波形按采样帧、UART按接收批量；不是实际采样/保护周期、最终刷新率或已测吞吐。按实测调整，不将手机全量查看等同持续全采样率传输。

## 断连恢复
检测断连或心跳失效→控制禁用、数据显示过期→有限快速重连及退避→自动发现/重新认证→获取真实快照和能力→恢复订阅与有效控制。无手动IP，不自动重发旧控制，不假称断连期间采样连续。连接代次与设备启动身份校验，清理失效队列，取消未执行过期命令；在途操作查询结果/状态，不强行抢占。普通断连不关闭正常输出；本机安全保护和既有业务保持。后台/主动断开不默认发起无限重连。具体心跳、超时、退避和队列容量待验证。
