## 页面与组件
480×480原生坐标，LVGL单一UI所有者（初期loopTask），按需创建控件；轻量生命周期 create/enter/update/exit/destroy，仅为职责示意，不强制五层包装。退出先注销页面刷新、定时器/动画/事件、解绑回调和控件指针，再释放控件；防止旧事件或地址复用误更新，业务状态与控件独立。命令通过S0-12统一入口，不直接操作HAL。公共按钮/弹窗/状态栏、触摸/实体按键/手势、导航与资源按需复用。中文文案集中、裁剪常用字库、数字字体、缺字回退；串口原始字节不因界面转义改变。具体LVGL版本、布局及字体/性能待验证。

## 两种工作模式
- 独立工具：从首页进入单个调试功能；退出时停止该本机会话拥有的工具并安全释放资源（含数控电源、PWM、通断激励），关闭与停止结果必须真实，失败不得假称已停止。手机/电脑连接及系统安全服务不随页面退出关闭；其他明确独立拥有者的业务不误关。
- 联合工作台：每项可运行调试功能作为可组合组件，默认可自由搭配，受真实硬件、资源、权限和安全例外约束。添加组件不等于开启危险输出；显式启停。工作台会话拥有所启动工具，切换组件仅释放/暂停不可见UI而不停止该会话中运行工具；移除组件停止其业务、确认安全释放；结束工作台统一停止该会话拥有的功能，不影响无关会话。普通断网按S0-13执行，不自动关闭正常输出，也不重放过期命令。
- 同一组件复用独立模式和工作台的页面、服务、状态及资源接口，不重复实现驱动，不为组件强制创建任务，不要求任意功能多实例。轻量会话管理记录工具及归属、运行状态，复用ResourceManager；不另造资源仲裁器。资源停止失败显示实际状态并阻止不安全切换；安全关断优先。
- UI候选：顶部横向可滚动工具状态卡片，下方仅一个完整操作区，添加/移除工具和结束调试入口；持续显示正在运行及危险输出状态。添加列表显示已选、可用、不可用及冲突原因。首版不强制复杂分屏/自由窗口/拖拽；具体布局待视觉设计确认。

## 特殊要求
沿用S0-10/13/14；PWM/频率计共享GPIO5互斥（待最终网表），测压/通断用户模式互斥；通断仅用于断电且安全检测有效的电路，工作台组合不能绕过带电保护，外部供电关系未知禁止激励；OTA为维护流程，暂停普通工具并关闭危险输出，不当作普通并行组件。实际ADC、LEDC、I2C、UART、无线、内存及功率资源均需验证；冲突默认拒绝，提示占用工具，可按用户确认安全停止旧工具后切换，不强抢资源。独立USB DAP、逻辑分析及CH549串口按实际PC端能力提供入口/说明，不假装ESP32拥有其数据或能停掉未受控的USB工具。系统设置、诊断、桌宠等不属于必需并行运行的调试组件，不影响其原有功能；诊断仅在设置中。

## 功能层级与显示
首页组织数控电源、测压/通断、示波器/PWM/频率计、I2C/串口/下载等调试工具、无线连接、工作台、桌宠、设置（显示、音效、OTA、诊断）和设备信息/引脚说明；只确定功能范围，最终布局/入口位置待视觉评审。桌宠采用预渲染3D风格资源、按帧/行解码、不可见暂停、内置回退资源；Wi-Fi主/BLE备用独立资源OTA。空闲动画、熄屏、低功耗休眠区分；熄屏不等于退出工具，深度休眠受活动业务约束，唤醒吞掉首次触摸/按键，不能误触输出或自动恢复已关闭的危险输出。

## 桌宠初始界面与显示状态（用户暂定确认）
开机进入桌宠，用户主动进入工具及返回初始页；使用工具时保留所在页面，任务结束不自动返回桌宠。无操作且无活跃调试任务时，时钟待机覆盖层→自动熄屏；唤醒恢复原页面，不改变导航栈、不自动恢复危险输出。桌宠仅在可见时渲染；时钟、熄屏和休眠不等同退出工具。现行规则见firmware-power-management.md末节，替代历史自动跳转桌宠建议。具体初始页交互、时间参数、动画及布局待统一UI评审，非最终UI。

## S4-A02/A03｜桌宠正式首页与四向导航（2026-11-27用户确认方向）
桌宠是开机后正式可交互首页，不是锁屏，不需要上滑解锁；保留可直接点击的功能菜单入口。首页四向手势（按手指移动方向）：下滑通知中心、上滑快捷设置、左滑功能菜单、右滑快捷工作台（常用工具和已保存模板）。首页四向导航不作为具体工具页的全局手势，避免与波形拖动、参数调节和列表滚动冲突。通知用于重要设备/连接/更新/任务事件，普通调试日志不进入；关键安全故障不得仅存通知中心。快捷设置仅开放实际支持且符合业务互锁的设置，切换通信或省电不得隐式停止业务或绕过保护；模板进入不自动开启输出。返回、独立工具退出、工作台归属及待机唤醒遵循现行S0-15和firmware-power-management.md。手势阈值、返回操作、实体键映射、设置项与通知详情、菜单排列、图标、桌宠美术及动效、颜色和尺寸均待后续UI评审；不冻结示意稿，不授权实施，不宣称实测。
