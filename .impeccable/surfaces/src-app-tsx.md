# Serial workspace

Mode: Operate. Windows desktop UI for long debugging sessions. Code-led implementation, as explicitly selected by the user. This is a replacement of the rejected interface, preserving functionality and the chosen ribbon-E brand.

## Direction contract

THESIS: A compact glass bench where raw traffic and up to 32 numeric channels remain one session. Single-row session actions, left navigation, log-first split and an anchored composer; no dashboard metric-card framing.

OWN-WORLD: Dark graphite and violet folded-ribbon brand; translucent curved navigation and panels, reflected top edges, consistent line icons and system UI type with monospaced bytes. Companion pale-glass theme. Four distinct functional curve colors.

STORY: Select a tool, inspect the source, send a command, compare channel values and collapse the plot when more log width is needed. Demo versus hardware is explicit. SWD and auxiliary measurement are excluded.

FIRST VIEWPORT: About 110px left navigation, one 55px header, left log 60% and right multi-channel plot 40%; compact current/min/max channel table. Composer stays at log bottom. Collapse makes the log full-width without losing input or stopping ingest. Narrow windows stack a compact plot above logs.

FORM: User-pinned Liquid Glass working interface, compacted after their screenshot feedback that the initial layout was too empty. The user-approved constraints override the engine's degraded assignment. seed:f2975ec9d92a35a4. No external challenger boards were used.
