| 事项 | 现行决定/验证边界 |

| BAT 8mil | 仅为屏幕VBAT支路，最大150mA（官方第13页）；1oz/32mm假设约11.6mV压降、1.75mW发热，保留 |

| 内部I²C | 上一轮累计SCL73.49/SDA75.32mm，各3过孔；外部I²C独立；不强制改线，最新长度未独立重测 |
| USB | 信号板新PICO DP9.62/DN7.51mm；CH549 DP35.35/DN26.61mm，DP含BOOT支路；12Mbps全速，不为等长大面积拆线，参考平面及枚举/传输待验 |

## 4. 打板前未闭环事项

- [ ] C16按1µF/25V、C18按10µF/25V等目标确定真实采购型号；旧库仍关联10µF/10V。核实 C23、C42～C46、C30、C114 等VBUS/USBVIN及 C21、C22、C25、C47 等VOUT电容耐压、有效容量；20V输出优先35V/50V（需符合芯片要求）。
- [ ] R28原理图20mΩ但库型号1206W3F500MT5E为50mΩ/1/3W；采购真实20mΩ、≥0.5W、兼容封装，核对 Kelvin及INA226校准。50mΩ在81.92mV满量程时约1.64A；20mΩ约4.10A理论测量量程，不代表允许输出电流。
- [ ] MP5016H U2的约15.2V典型钳位与BQ25606推荐输入上限13.5V的异常保护间隙复核；U10 MODE悬空、R13 604Ω的限流/OVP/反灌与20V输出及功率预算核对。不要默认保护闭环。
- [ ] 测压/通断负压、带电误接、关机反供电及默认关断保护复核；禁止市电、未经验证的浮地测量。目标±20V不是已验证耐压。
- [ ] 检查所有烧录/恢复路径；GPIO45=LCD_TE启动绑带及ESP32单独复位风险。CHG_PG/CHG_STAT未接主控，不能直接读取状态，是否补线待用户决策；不影响基本充电。
- [ ] 实物连接器机械配对/高度、外壳、电池/NTC/保护板、天线、热与安装干涉。
- [ ] 重铺铜、原理图PCB同步、正式 ERC/DRC、BOM、Gerber、钻孔、板厚铜厚和层数确认；保存实际下单版本与订单凭据。
